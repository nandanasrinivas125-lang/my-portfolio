MY PORTFOLIO - QUICK START
1. Extract this ZIP and open the my_portfolio folder in VS Code.
2. Open index.html in a browser, or use the Live Server extension.
3. Replace Your Name, education, email, LinkedIn and GitHub details.
4. Replace project href="#" links with actual repository/live-site links.
5. Update Mentora's description and technologies to match your actual project.
6. Replace images/profile-placeholder.svg with your photo saved as images/profile.jpg,
   then change the profile image src in index.html to images/profile.jpg.
Four project cover illustrations are included in the images folder.
